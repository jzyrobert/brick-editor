These minimal drivetrain excerpts derive from Philippe Hurbain's public OMR models [42042-1](https://library.ldraw.org/library/omr/42042-1.mpd) and [42043-1](https://library.ldraw.org/library/omr/42043-1.mpd), under the models' CCAL/CC BY 2.0 attribution terms. The fixtures retain author/license/source headers and the exact original model SHA256. Original nested placements were composed into world coordinates; official part geometry remains in the pinned library with its original headers.

The drivetrain excerpts contain only the actual motor mounting, inserted axle and one neutral selector shaft. The routing excerpts contain the actual two crane worm seats, four Arocs exterior bevel seats and both Arocs differential case/internal-gear assemblies. It is an interface regression fixture, not a complete or independently functioning set. Complete licensed originals and official instruction PDFs remain private maintainer research artifacts. No omitted flexible assembly, chassis member or operating function is claimed to be simulated by these excerpts.
