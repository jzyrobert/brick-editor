# Sol 6.1 high pilot evidence

[Results and limitations](../../../../docs/SPATIAL-PILOT.md). The initial schedule ended on 12 October 2026: 40 calibration cases and 72 creative cases. This is a completed exploratory study, not a promoted prompt/default or a published gallery collection.

## Files

- `calibration.json`, `creative.json`: frozen executed manifests; `feedback-planned.json`: separate 36-case study, not executed.
- `calibration-results.json`: all 40 calibration outcomes and original/evaluator-v2 scores.
- `creative-results.json`: all 72 creative outcomes, failures, usage, reference coverage, construction warnings and blinded visual scores. Its original generated bytes are preserved because the evidence ledger hashes this file.
- `creative-evidence.json`: original statuses, source/artifact hashes, audit/input identities, anonymous presentation IDs, actual cameras, four-view image hashes and assessments for every case.
- `creative-effective-inputs.json`: all 72 exact filled benchmark prompts, lengths/hashes, case metadata, original order and compiler/source identities. Native transport context is additional and remains in the private raw archive.
- `creative-execution-phases.json`: all 21 execution phases, quota readings, source identities and host supervision/cooldown amendments. Failed or successful cases were never repeated.
- `creative-cases/<case-id>/`: original `submission.txt`, `freeze.json`, and `compilation.json` / `build.mpd` when available. `script.json` is an extracted compiled script, not a rewrite of the submission. Empty/partial failed submissions are retained.
- `visual-protocol.json`, `analysis-protocol.json`: frozen assessment and analysis rules. `phase-2-continuation-protocol.json` records the first host correction before continuing unattempted cases.

All 42 submitted creative builds have four rendered views and completed assessments. The other 30 remain unevaluated visually. Analysis records 19 infrastructure failures and 11 model output-budget failures; the original ledger retains 20 infrastructure and 10 model failures, because the first v2 budget failure was misclassified. No source/status is overwritten to correct that taxonomy.

The primary task-weighted combined-minus-control difference is +0.10/24, descriptive task-bootstrap 95% interval [-0.50, +0.60]. Destroyer is missing shape/combined builds and is excluded from that five-task contrast. The numeric report retains it. The study does not establish an improvement. One model family, one automated reviewer, development subjects, low retrieval and unequal surviving samples limit inference.

## Verification and reproduction

These commands make no model requests:

```sh
export PATH=/tmp/brick-node/node-v22.14.0-linux-arm64/bin:$PATH
FORCE_COLOR=0 npx vitest run --project unit tests/unit/spatial-pilot-results.test.ts

# Reconstruct effective inputs in a fresh directory:
npx tsx scripts/spatial-benchmark.ts --manifest fixtures/spatial-benchmark/studies/sol-high-pilot/creative.json --out .local/new-pilot-preflight --mode preflight

# Recompile a real accepted script without reference to an image:
npm run cli -- build --script fixtures/spatial-benchmark/studies/sol-high-pilot/creative-cases/piplup--combined--3/script.json --output .local/replayed-piplup.mpd
```

The recorded handoff preflight reproduces all filled inputs, order and compiler bundle hash. The example recompiles to 1,062 parts and byte-identical MPD SHA-256 `5fd60f5fb4f6b660e789557338a21742d0ebe6a4fbb32211aaa1c6fa9e393c41`; construction warnings remain. Runtime timings in a new CLI report may differ. Compilation seeds do not make stochastic model generation reproducible.

The unit ledger checks verify all frozen files/scripts, complete scheduled IDs, original status preservation, exact input hashes/lengths, assessment/view completeness, missingness and an independently calculated task-weighted primary mean. The full implementation tests separately cover the observation/isolation/geometry contracts. No test result here certifies stability, clutch strength or executable assembly order.

## Private local handoff

`.local/spatial-pilot-remaining-supervision-v2/final-checkpoint` pools every creative phase and preserves sources, audit transcripts, compiler bundle/input graph, raw native requests/streams, actual adapter implementations and quota history. `.local/spatial-pilot-sol-high-creative-visual-v1` retains all 168 PNGs and private reviewer transcripts. `.local/spatial-pilot-sol-high-calibration-v2` retains calibration originals. These directories contain private native context and are not committed or uploaded. Image identities and cameras are public here; the pinned renderer can reproduce views from archived MPDs.

There is no path back from evaluation to generation. No new default, gallery entry, assembly language or design-guidance treatment was introduced. The feedback study, alias/automatic-exposure comparisons, stronger/held-out tasks, another model family, independent human review and physical verification remain separate future work.
