# Brick Editor

A local-first, phone-first gallery and interactive LDraw workshop in the browser (React, TypeScript, three.js). Browse generated responses to a shared prompt, compare models and step inside them. Build with official LEGO parts, open real LDraw models and official sets, walk around and drive what you built, follow it step by step, take studio photos and export parts lists. Live at **[bricks.robertj.in](https://bricks.robertj.in/)**.

It is a working development build of the roadmap in [spec.md](spec.md), not a finished P0–P3 release; what is done and what is not is tracked in [docs/STATUS.md](docs/STATUS.md) and [TODO.md](TODO.md). There is no application backend, account or telemetry: models are parsed and saved in the browser. The one server-side piece is a small Cloudflare Pages Function that proxies official set files from LDraw.org.

## What it does

- **Gallery.** Browse builds that AI models made from the same brief, published to the [agent gallery](docs/GALLERY-PLAN.md): shared viewing angles, model and effort filters, two-build comparison, and a detail page with a live, spinnable 3D view in the Realistic look. Gallery and Play are the primary modes; every gallery model can use Build, Instructions, Photo and Project through Tools. See [gallery behavior and sources](docs/GALLERY.md).
- **Build.** Place parts from a curated catalogue of 224 parts or search the complete official LDraw library (24,735 parts, loaded on demand and cached offline), in the colours each part was really made in. Stud connectors snap parts together (side studs, jumpers, arches, door hinges); _Snap together_ only accepts parts that connect. Navigate, Select (box and lasso in 3D), Inspector transforms, layers, clipboard, arrays, fills, workplanes, submodels, section cuts, floors, measure, checkpoints, model health and undo. Positions are in LDraw units (20 per stud, 8 per plate, −Y up). See [connectors](docs/CONNECTORS.md).
- **Open.** Local `.ldr`/`.mpd`/`.dat`/`.brickproj`, build scripts (`.json`), share links, saved projects, sixteen sample builds (Market town, Cathedral, Harbour, Corner café, Windmill farm, Lighthouse, Off-road jeep, Railway station, Playground park, House with garden, Small castle, Roadster car, plus Twin motor table, Motor & gears, Large motor and Rack guide; see [templates](docs/TEMPLATES.md)), the 1,470 sets of the LDraw [Official Model Repository](docs/OFFICIAL-MODELS.md), and builds from the [agent gallery](docs/GALLERY-PLAN.md). Large models (up to 200,000 parts on desktop, 150,000 on phones) draw a loading skeleton at once and fill in from the ground up.
- **Look.** Standard (optional soft outlines), Realistic and a path-traced Photo look that share one studio lighting; scene backdrops; exploded floors and an [Anatomy](docs/ANATOMY.md) view that takes a model apart by submodel. See [rendering](docs/RENDERING.md).
- **Play.** First- and third-person walking, flying and driving with a touch HUD; physically seated official doors open automatically; source-verified hinges, physically mounted motors and vehicles; reviewed session-only Technic setup; opt-in Rapier dynamic physics; trains that run on official track and can be driven from the cab. See [Play physics](docs/PLAY-PHYSICS.md), [trains](docs/PLAY-TRAINS.md), [vehicles](docs/PLAY-VEHICLES.md).
- **Instructions and parts.** A follow-along step viewer (the model's own STEP lines or generated steps), a parts list with CSV and Rebrickable CSV export, instruction plans published as PNG/HTML/PDF, and a BrickLink Wanted List export with a "Check your parts" review. See [instructions](docs/INSTRUCTIONS.md).
- **Save and share.** Verified autosave to IndexedDB, named checkpoints, native `.brickproj` bundles, LDraw `.mpd` export, PNG captures with manifests, self-contained share links and an opt-in offline install.
- **Automate.** `/?automation=1` exposes `window.brickEditor` ([API](docs/API.md)); a Node CLI runs the same core without a browser ([CLI](docs/CLI.md)); agents can design builds as compact [build scripts](docs/AGENT-BUILDING.md) that compile to checked LDraw.

## Run, test, build

Requires Node **22.14 or later**.

```sh
npm ci
npm run dev                       # Vite dev server
npm test                          # unit + integration tests (Vitest; CLI tests drive Chromium)
npx tsc -b                        # type-check
npm run format:check              # Prettier; CI fails on formatting
npm run library:validate          # pinned LDraw packs, thumbnails, locks
npx playwright install --with-deps chromium
npm run test:browser              # build, then the full Playwright suite
npm run test:browser:quick        # build, then skip @heavy (path-traced) and @perf tests
npm run build && npm run preview  # production bundle
```

Browser tests run Chromium with SwiftShader software WebGL2 at desktop and phone viewports (1440 × 1000, 1080 × 1800, 360 × 800 and others); they are layout and behaviour tests, not physical-phone measurements. Projects, tags and worker settings: [running the browser suite](docs/VERIFICATION.md#running-the-browser-suite). Benchmarks: `npm run test:performance`, `npm run test:stress`; results in [docs/reports](docs/reports).

```sh
npm run cli -- validate --input fixtures/ldraw/nested.mpd
npm run cli -- build --script fixtures/build-scripts/townhouse.json --output townhouse.mpd --render townhouse.png
npm run cli -- parts search "cheese slope"
npm run cli -- inventory --input build.brickproj --format bricklink-wanted-xml --output wanted.xml --report wanted.report.json
npm run cli -- render --input fixtures/ldraw/studio.mpd --camera fixtures/renders/interior.camera.json --output interior.png
```

## Deploy

Every push to `main` runs [the workflow](.github/workflows/cloudflare.yml): build once, then format, unit and library checks and the browser suite in eleven parallel shards; only when all pass is the tested `dist/` published to Cloudflare Pages with Wrangler. Other branches can be validated by manual dispatch but are never published. Details: [deployment](docs/DEPLOYMENT.md).

`dist/` is plain static hosting plus `functions/api/omr/[file].ts` (the official-set proxy). `BASE_PATH=/sub/ npm run build` builds for a sub-path. The page ships a strict same-origin CSP (no `unsafe-eval`; `wasm-unsafe-eval` for the lazily loaded Rapier engine); serve it over HTTPS for Web Crypto and the clipboard. `npm run deploy:check` keeps the build within Cloudflare Pages file limits.

## Parts library and licences

The app ships pinned, hash-verified packs built from the official LDraw library: the curated catalogue (`public/libraries/catalogue-2026-09-29`), the complete library in content-addressed chunks (`ldraw-full-2026-09-28`, 86 MB), derived connectors, `!TEXMAP` textures and thumbnail sprite sheets. They are generated by maintainer scripts (`npm run library:*`, `python3 scripts/fetch-library.py`), committed, and never rebuilt in CI; a new LDraw release goes through `npm run library:update`. Every file keeps its authors and licence header. Marketplace mappings are reviewed BrickLink evidence plus derived keyword tables; colour availability uses a pinned Rebrickable snapshot (free with attribution). Official set models are CC BY 2.0 and load unmodified from LDraw.org. Provenance and procedures: [status](docs/STATUS.md#complete-official-library-2026-09-28), [LDraw notices](public/notices/LDRAW.txt), [dependency notices](public/notices/DEPENDENCIES.txt), [fixture provenance](fixtures/PROVENANCE.md).
