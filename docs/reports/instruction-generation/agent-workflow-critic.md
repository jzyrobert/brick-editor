## Fixed numerical rubric

| Score | Hobbyist usability meaning                                                                                                                    |
| ----- | --------------------------------------------------------------------------------------------------------------------------------------------- |
| 1     | Major procedure reconstruction remains necessary; important operations cannot be understood from the presented sequence.                      |
| 2     | Some useful local sequences, but critical whole-model construction, receiving or handling gaps remain.                                        |
| 3     | Useful editable draft; ordinary operations are understandable and unresolved decisions are specific enough to review.                         |
| 4     | Largely self-contained guide with limited reviewer intervention; the important tested windows explain construction, interfaces and placement. |
| 5     | Evidence from actual builders establishes successful physical use. This desk experiment cannot earn5.                                         |

I judge pictured part selection and quantities; understandable ordered actions; separate build/fit/place semantics; visible receiving interfaces and access; localized uncertainty; and diagram/caption/phone/print readability. I do not raise scores for fewer steps, more generic warnings, a green audit, a larger number of labels, or an agent's rationale. A view of the final part is insufficient when the action still requires reconstruction. Scores apply to the inspected evidence and retain that scope; selected windows cannot establish every intermediate operation's quality.

## Separate invariant gates

Before an edited plan is accepted, require exact source/reference/colour/pose preservation, exact-once occurrence introduction and inventory ownership, complete generated drawing owners, valid nested build/join replay, destination receivers present in the actual assembled workbench, and persistence without stale generation or CAD claims. Root assembly must omit unjoined parents and children. A scene placement must not invent a mating connection. Editing must invalidate affected derived claims. Audit success establishes these invariants, not physical fit, stability, insertability or usability. Unsupported requests/refusals stay explicit.

## Frozen comparison and review protocol

Each round must archive its exact prompt/tool revision, source hashes, library locks, proposal/result/audit, and capture manifest. Compare each edited case to its own unchanged deterministic baseline and the previous completed round, using opaque source aliases and stable action IDs as well as displayed numbering. Record whether builders revised earlier plans or started anew and which critic feedback they received. This is cumulative refinement, not an independent randomized agent ranking.

I inspect the actual diagrams before reading the builder's explanation. Review consecutive prior/current/next windows for risky edits, bare receiving state, first/last module construction and placement, plus enough retained programme context to detect regressions. Source integrity and affected/unaffected operation data are independently checked; reused raster evidence must carry an exact equivalence/provenance record. Record exact images and operation/alias IDs, accepted repairs, new failures, tool/prompt remedies and measured capture/time data only when logged.

For Roadster, inspect foundation/body coherence, all affected wheel preparation/fit/placement and intended receivers. For House, retain frame/door/glazing order, exposed fitting before closure, roof workbench/placement and any edited loose decoration.
