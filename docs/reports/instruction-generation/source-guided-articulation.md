## What the algorithm uses

This path explicitly uses authored OMR hierarchy and STEP records as an ordering
prior. It does not reconstruct those records from unordered geometry. Eligible
sections require complete current source membership, bounded dimensions, proper
near-rigid frames and unambiguous ownership. Existing typed workbench programmes
retain the previous planner. `useSourceSteps: false` disables the source prior.

The bounded event scheduler retains support, host and access prerequisites at
leaf introduction, and separately verifies actual workbench availability. A built
sibling must be joined before another object can use it. Parent construction may
resume after a child join; the scene receives a parent only after its complete
build. Contraction cycles, conflicting source order, mixed ownership and budget
exhaustion refuse the candidate atomically.

The positive receiver profile matches both finite clip cylinders on 60470b to
the finite handle on 48336. It checks reciprocal uniqueness, endpoints, signed
axes and propagated display-frame error against pinned source closure. The actual
raw radial discrepancy is approximately 0.028 LDU. Separately normalized display
frames never alter source geometry, strict collision tolerances or connector
coverage. Missing, ambiguous, mirrored, scaled, sheared, excessively rounded or
shadowed source definitions do not qualify.

Project-first geometry expansion now resolves complete custom-part dependencies
with bounded work and conservative refusal. Shark's custom towball remains one
original source occurrence; its 648-triangle closure is not substituted with an
official inventory identity. The loader transports this evidence through the
generation worker. The initial admitted head/jaw does not contain these towballs,
so their later missing pictures and unreviewed interfaces remain open.
