I would make three small changes to the process:

1. Clarify that curves and tiles are examples of intentional surface treatment, while coherent brick-sculpted treatments are also valid. This could reduce pressure toward horizontal curved shelves, but could also excuse poorly shaped stepped masses.
2. Include existing warning records and their locations in the existing draft-check response, distinguishing them from blocking errors. This would expose unresolved evidence sooner, but noisy warnings could encourage overcorrection.
3. Add attachment type to search results where known—stud, axle, pin or clip—and mark unknown connection data explicitly. This would improve assembly reasoning without adding a solver, but incomplete metadata could unfairly discourage otherwise useful parts.
